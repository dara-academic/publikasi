# Bedah Publikasi | Dr. Despinur Dara

Etalase sekaligus media pembelajaran publikasi ilmiah. Situs statis, tanpa kerangka kerja apa pun,
siap dilayani langsung oleh GitHub Pages.

Situs ini membedah setiap karya dalam bahasa Indonesia, mulai dari latar belakang, research gap,
novelty, landscape teori, metode, temuan, hingga bagian yang jarang dibuka orang, yaitu perjalanan
review beserta catatan reviewer per ronde. Tersedia dalam dua bahasa, Indonesia dan Inggris.

## Struktur

```
index.html              beranda (Indonesia)
scopus/                 kluster paper Scopus (1 indeks + 5 halaman bedah)
sinta/                  kluster paper SINTA (1 indeks + 1 halaman bedah)
buku/                   kanal buku
proses-review.html      manuskrip yang sedang dinilai
proses-terbit.html      naskah yang sudah diterima, menunggu terbit
lesson-learned.html     pelajaran dari perjalanan publikasi
tentang.html            profil penulis
en/                     cermin seluruh halaman dalam bahasa Inggris
assets/                 gaya, ikon, foto, sampul jurnal, dan PDF akses terbuka
```

## Cara memperbarui

1. Sunting berkas HTML terkait.
2. Perbarui juga padanannya di `en/` agar kedua bahasa selaras.
3. Simpan, lalu `git add`, `git commit`, dan `git push`. GitHub Pages menerbitkan ulang otomatis.

## Catatan isi

PDF yang disertakan di `assets/papers/` hanya artikel berlisensi akses terbuka (Creative Commons).
Artikel berlangganan tidak diunggah; halamannya menyediakan tautan resmi jurnal dan opsi menghubungi
penulis. Gambar sampul jurnal ditampilkan kecil semata sebagai penanda identitas jurnal.
